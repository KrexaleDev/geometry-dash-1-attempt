# Geometry Dash 1 Attempt

A Geode mod that adds a one-attempt gameplay system to Geometry Dash.

## Features

- One attempt per level
- Level filters
- Moderator tools
- Level management
- Simple and lightweight UI

## Installation

Install the mod through the Geode ecosystem.

## Usage

Once installed, the mod automatically enables its one-attempt system.

Additional options and level management tools are available through the mod interface.

## Compatibility

- Geometry Dash: 2.2081+
- Geode: v5
